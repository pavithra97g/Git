#  Git & GitHub Fundamentals

## Objective
Learn and practice Git and GitHub basics including repository setup, commits, branching, merging, and rollback.

## Tools Used
- Git
- GitHub
- Visual Studio Code

## Tasks Completed
1. Installed Git and configured username and email.
2. Initialized a local Git repository.
3. Created files and tracked changes using git status, git add, git commit.
4. Created a GitHub repository and linked it with local repo.
5. Pushed commits to remote repository.
6. Created a branch, made changes, and merged it back to main.
7. Practiced rollback using git log, git reset, and git checkout.
